Prototype parts kits

TESTING NOT COMPLETE

These are prototype hardware projects. Assembly, fault-finding and firmware development are required. Compatibility and operation are not yet qualified. Neither current project includes a completed, qualified firmware release.

Incomplete physical testing does not by itself prevent a prototype parts kit being offered for sale. A complete, revision-matched parts list and a successful live supplier quote are still required. Both projects are undergoing exact sourcing checks. RODDY supplies the Link Commander RP2040-Zero and the Keychain Kreatures screen, ESP32-S3 SuperMini and populated power board. These are excluded from the Mouser completion kits. Current kit templates remain incomplete and are not yet accepting payment.

Keychain Kreatures retains its existing C7 mainboard and P5 power-board design. The P5 board arrives populated; the completion kit does not contain loose P5 SMT components.

Pricing and delivery

Parts-kit prices follow the store’s adjustable percentage markup on supplier landed costs. Prices and shipping are checked for your delivery address before payment. Paid orders keep the accepted price and exact BOM revision. RODDY hardware bundles and Mouser components travel separately and have separate fulfillment records.

If costs make an automatic order unprofitable, purchasing is suspended for review. RODDY must resolve the price or parts issue before ordering; a supplier price change does not silently increase an already-paid order.

Owner: reusable Mouser kit carts

  1. Open the product editor’s Parts kit tab. Enter a revision and exact Mouser part numbers, or import its BOM JSON.
  2. Quantities mean supplier order units per kit. Account for packs, order minimums, multiples, sockets and harness components. For example, Adafruit 3101 is a pack of ten buttons; nine switches require one pack.
  3. Keep an incomplete list in Draft. Mark it Complete exact BOM only when it matches the actual board and includes every advertised part. This is a procurement status, not physical qualification.
  4. Add the red prototype warning in Details. Set availability and pricing deliberately; fully assembled editions remain Pricing TBA.
  5. Publish. In Suppliers → Kit carts, choose the number of kits and country, then build a fresh cart. This saves an owner-only API cart reference; it does not submit an order or charge a card.
  6. For a saved project on the Mouser website, download the BOM CSV, import it into My Mouser, and save the cart as a project there. API cart references are not website Share Access IDs.

Automatic checkout always creates a separate cart from the frozen BOM. Customer orders never reuse a shared mutable template cart. Orders shows the original kit revision and expanded quantities alongside separate RODDY hardware-shipping records.

Manage markup under Suppliers → Automatic retail pricing. Maintain on-hand hardware-bundle stock in Orders → Inventory, and hardware-bundle retail/shipping rates in the product editor. PCBWay board procurement is not automated by this change.

Sources: Mouser project/cart sharing; Mouser API guide; Adafruit 3101 pack contents. Supplier stock and shipping eligibility can change.
