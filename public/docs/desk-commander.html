Install and update

Download the purchased DESK COMMANDER X16 ZIP, then extract it into the root of a FAT32 SD card. Keep all files inside DESKCMD together. Open DESKCMD/AUTOBOOT.X16 from your X16 launcher. From BASIC, enter these commands separately:

CD "DESKCMD"
LOAD "DCMAIN.PRG",8,1
RUN

Targets Commander X16 ROM r49. This is X16 software, not a Windows or Linux desktop app. Before updating, exit Desk Commander and back up your DESKCMD folder, including DCSTATE.BIN and your documents. Replace program files while preserving your saved data. The ZIP includes README.TXT with setup and controls.

Connect Wi-Fi and chat

Offline apps work without networking. Online features require the TexElec Commander X16 Serial & ESP32 Network Card running ZiModem. The supported configuration is IO7-low $9FE0, 115200 baud, 8N1, RTS/CTS, with Option Pin A high.

  1. Open Network Setup: D detects the card, W scans for Wi-Fi, select your network, J joins, and I checks connection status.
  2. Open Comms. HOST is already set to 143-244-168-180.sslip.io. No host search or manual entry is needed on a fresh install. Blank saved hosts fill automatically on upgrade; a custom host stays unchanged. To switch a custom host back, use HOST and enter this hostname without https:// or a path.
  3. Choose USER, enter a username and an 8–24 character password, then press SYNC. A new name creates an account; an existing name requires that account's password.
  4. Open the square conversation selector and choose WELCOME. Type in the bottom field; Enter or SEND sends your message.
  5. Use +FR to add a friend, +GRP to create a group, and MEM to manage group membership. DEL removes a selected friend or leaves/removes a group according to your permissions. The face picker adds emoji. Friend indicators show green online, yellow away and red offline.

You can also use the browser chat tester with the same account and conversations. Chat requires an internet connection and the selected server to be available. Desk Commander does not save your Wi-Fi password; ZiModem may remember its own configuration.

Everyday controls

  • Desktop: click an app, or select with arrows and Enter. Esc or the red X closes the current app. Use arrows, mouse wheel or scrollbars in scrollable views.
  • Files: Enter/Open opens a selection; N creates a file, F a folder, R renames, M moves, D deletes and U goes up. Opening a PRG/X16 program exits Desk Commander to run it; reopen Desk Commander afterward. Raw binaries need their own loader.
  • Text Editor ++: F2 saves and F4 opens Save As. Text files are limited to 2,047 bytes; larger/binary files are rejected rather than partially overwritten.
  • Notes: select a note and press Enter to read it, then choose Edit to change it. Arrows/wheel scroll the reader; Tab moves between actions.
  • Calendar: click a date or dashboard event to open details. Done or Esc saves event text and closes the editor.
  • Desk Directory: type to search, Insert adds a contact and Enter edits. Open the card to read every field, including long email addresses.
  • Settings: cycle themes and mouse styles; choices save to the SD card. Sound can be muted here.
  • Market Watch: needs networking. The default current-price feed needs no key; KEY accepts an optional Finnhub API key. Quotes depend on the upstream feed and are not a trading terminal.

Alpha notes and account privacy

This is an alpha release. Keep backups; physical SD recovery and long-session behavior still need more hardware testing. The masked chat password is stored in DCSTATE.BIN, so use a unique password and keep the SD card private. ZiModem HTTPS encrypts traffic but does not verify server certificates. Chat is not end-to-end encrypted; the selected server can read messages. Never include your saved state in a shared ZIP.
