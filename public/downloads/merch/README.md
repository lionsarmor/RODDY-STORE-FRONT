- Editable vector: `roddy-hoodie-white-red-front.svg`.
- Design: original full RODDY lettering and capsule outline in pure white;

- Source geometry: `public/img/logos/RODDY_SVG_BRAND_PACK/full_logo/outline/roddy_full_white_red_outline.svg`.

In Printify select Black and the front DTG print area, then upload the PNG and
check its size/placement in the preview. The black background comes from the
garment; it is not printed by this file. The canvas matches the print-area pixel
dimensions the owner supplied. Final placement and Printify's resolution check
must be reviewed in the product editor before saving the production product.

This file prepares the artwork; it does not create or order a Printify product.
